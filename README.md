# PANDEMIC ZERO — パンデミック・ゼロ

ブラウザで動く、肩越し視点のサバイバルホラーTPS（three.js製・ビルド不要）。

## 遊び方

静的ファイルとして配信するだけで動きます（`file://` 直開きはES Modulesの制約で不可）。

```bash
python3 -m http.server 8000
# http://localhost:8000 を開く
```

Vercel では Framework Preset を「Other」にして、そのままデプロイできます（ビルド不要）。
グラフィックは初代プレイステーション風（320×240・4:3）。パソコンでは4:3の画面をブラウン管テレビの枠の中に表示します。スマホも縦持ち9:16・横持ち16:9の固定比率でブラウン管の枠の中に表示し、操作ボタンはゲーム画面の中に置きます。
動作が重い端末では `?low` を付けると影オフ・低解像度になります（例: `http://localhost:8000/?low`）。

## 操作

| キー | 動作 |
| --- | --- |
| WASD / Shift | 移動 / 走る |
| マウス | 視点 |
| 右クリック（長押し） | 構える（構え中はゆっくり移動、レーザーサイト表示） |
| 左クリック | 構え中は射撃、構えていなければナイフ |
| F | ガード（1回押すと約0.5秒構える。攻撃の直前に押すとジャストガード） |
| R / 1・2・3 / ホイール | リロード / 武器切替 |
| H / G | ハーブで回復 / 手榴弾 |
| Q | クイックターン（180°） |
| E / Enter | 商人と取引 / 次の章へ |
| Tab | アタッシュケース（ハーブ調合） |
| SPACE | 掴まれたら連打、処刑人の突進は回避（QTE） |

スマホでは画面上のスティックとボタンで操作できます。

## ステージ

タイトル画面でステージを選べます。

- **STAGE 1 赤霧の村**：霧の山村。寄生された村人、寄生体、ボス「処刑人」。
- **STAGE 2 街・警察署（テスト版）**：村から戻ると街はゾンビであふれている。燃える大通り → 封鎖線 → 雨の夜を耐え抜き、「警察署へ」の章で入口へ向かうと暗転して署内へ。ロビー → 停電 → 留置場の暴動 → 地下駐車場（ボス「変異体」）。
- **STAGE 3 地下鉄（テスト版）**：警察署から地下道へ。地下道 → 駅のホーム → 線路の暗闇 → 車両倉庫（ボス「掘削者」）。
- **STAGE 4 地下研究所（テスト版）**：車両倉庫の隠し扉の先。研究棟入口 → 警報 → 培養槽 → 発生源（ラスボス「原初体」）。

警察署・地下鉄・研究所ではフラッシュライトが点きます。

## 構成

- 各ステージ全4章（最終章はボス戦。STAGE 2 は街3章＋警察署へ＋署内4章）
- 頭や脚を撃つと敵が怯む
- ガード：攻撃や掴みに合わせてFを押すとダメージを軽減し、相手をのけぞらせる。押した直後の短い時間に受けるとジャストガード（ダメージ1割・大きくのけぞる）。長押しはできず、ガード中は移動が遅くなる
- 第3章以降、頭を吹き飛ばすと寄生体が姿を現すことがある（ショットガンが有効）
- 章の合間に旅の商人が現れ、武器の購入・改造・宝物の売却ができる
- ボスの突進は回避して壁に激突させると大きな隙ができる。背中の光る核が弱点
- モデル・テクスチャ・効果音・BGMはすべてコードで生成しています（外部アセットなし）
